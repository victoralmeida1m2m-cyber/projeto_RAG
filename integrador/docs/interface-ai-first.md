# Interface AI-first workspace

- Conceito: versão 1 (minimalismo profissional) + versão 3 (assistente como primeira página).
- Paleta: fundo carvão/verde profundo, acento lima, componentes de dados discretos.
- A experiência inicial abre o assistente com documentos reais do Neon, campo de prompt e exemplos.
- A animação Vector Wordmark fornecida pelo usuário ("EDITAL") aparece atrás do assistente, nunca sobre o conteúdo; nos dispositivos pequenos ou com preferência de movimento reduzido, usa fallback estático.
- O menu incorpora o traço irregular Scribble Loop Nav fornecido pelo usuário, adaptado para botões reais, clique e navegação por teclado.
- Upload, arquivo, comparação, login, limites de IA e APIs existentes preservados.
- Alterações isoladas em `feat/interface-ai-first-workspace`, publicar primeiro em Preview e depois em Production após testes.
